# Homework 1 Sample Problem

## Worcester Burger

Write a Python program for a local restaurant called Worcester Burger. The restaurant allows customers to build their own meal by choosing a patty, bun, side, and drink. Your program should contain the complete menu with prices, the customer's specific order, calculate the cost of the meal, apply Massachusetts sales tax, apply a gift card, and create a final order summary.

The program should be set up in such a way so that it could apply to any combination of patty, bun, side, and drink for a unique customer's order, even though this only asks for one person's specific order.

## Menu

### Patties
- Wagyu — $14.08
- Beef — $12.16
- Chicken — $11.20
- Veggie — $11.20

### Buns
- Brioche — $2.56
- Pretzel — $2.56
- Sesame — $2.08
- Veggie Wrap — $1.76

### Sides
- Plain Fries — $6.08
- Seasoned Fries — $7.20
- Onion Rings — $5.60
- Salad — $5.12

### Drinks
- Soda — $3.52
- Lemonade — $3.04
- Water — $0.00

**Massachusetts sales tax:** 6.25%

## Customer's Specific Order

Your customer's name is Dan.

Dan's Order: Beef Patty, Brioche bun, Seasoned Fries, and Lemonade.

Dan also has a $10.00 gift card that he would like to use toward his order.
